# 콩메모 (Kong Memo) — 폰에서 클로드 코드를 쓰고, 메모를 AI에게 넘겨주는 메신저형 메모 앱

> 카톡 쓰듯 나에게 메모를 보내면 쌓이고, 그 메모를 PC의 클로드 코드가 직접 읽습니다.
> 그리고 **밖에서 폰으로 PC의 클로드 코드에게 일을 시킬 수 있습니다.**

이 저장소는 콩메모와 PC를 연결하는 **두 개의 작은 프로그램**을 배포합니다. 앱 본체는
Google Play와 웹에 있습니다.

| | 방향 | 하는 일 |
|---|---|---|
| **PC 리스너** | 폰 → PC | 폰에서 보낸 메시지를 PC의 클로드 코드가 받아 실제로 작업합니다 |
| **MCP 서버** | PC → 콩메모 | PC의 클로드 코드가 콩메모에 쌓인 메모·링크를 직접 읽고 씁니다 |

---

## 📱 콩메모 받기

- **안드로이드**: [Google Play에서 받기](https://play.google.com/store/apps/details?id=com.hbookhouse.kongmemo)
- **아이폰 / 맥 / PC**: [웹 버전 바로 쓰기](https://hbookhouse.com/kongmemo/app) — 설치 없이 브라우저에서 그대로 동작합니다

둘 다 같은 계정으로 실시간 동기화됩니다.

---

## 1. PC 리스너 — 밖에서 폰으로 클로드 코드 시키기

텔레그램 봇으로 클로드 코드를 쓰는 방식과 같은 구조인데, **봇을 따로 만들 필요가 없습니다.**
앱에서 방을 하나 만들고 명령어를 붙여넣으면 끝입니다.

```
지하철에서 폰으로:  "어제 고친 로그인 버그 테스트 돌려줘"
        ↓
PC의 클로드 코드가 실제로 실행하고, 결과가 폰으로 돌아옵니다.
```

**특징**

- **대화가 이어집니다** — `/clear` 치기 전까지 맥락을 기억합니다 (Claude Agent SDK 사용)
- **리스너 하나 = 프로젝트 하나** — 터미널에서 `cd`한 그 폴더가 작업 폴더가 됩니다
- **위험한 도구는 기본 차단** — 파일 쓰기·명령 실행은 앱에서 켜야 열립니다
- 응답을 놓치지 않습니다 — 폰이 꺼져 있어도 메모로 남아 나중에 확인됩니다

**설치** — 앱의 `AI 커맨드 센터 > 프로젝트`에서 명령어를 복사해, 작업할 폴더에서 붙여넣으면 됩니다.

---

## 2. MCP 서버 — 클로드 코드가 내 메모를 읽게 하기

평소 쓰던 클로드 코드가 **콩메모에 쌓인 내 메모를 직접 검색하고 정리**할 수 있게 됩니다.

```
"콩메모에 저장해둔 유튜브 링크 전부 찾아서 옵시디언에 정리해줘"
"콩메모 '할일 목록' 방 보고 이번 주 할 일 요약해줘"
"방금 정리한 내용 콩메모 '중요 메모' 방에 넣어줘"
```

폰으로 아무 데서나 모아둔 것들이, PC에서 작업할 때 그대로 재료가 됩니다.

**제공하는 도구**

| 도구 | 하는 일 |
|---|---|
| `list_rooms` | 방 목록과 각 방의 메모 개수 |
| `get_room_items` | 특정 방의 메모 읽기 |
| `search_memos` | 전체 검색 (종류별 필터 — 링크만, 파일만 등) |
| `add_memo` | 새 메모 추가 (폰·웹에 바로 동기화됨) |

**설치** — 앱의 `AI 커맨드 센터 > API & 확장`에서 명령어를 복사해 터미널에 붙여넣으면,
다운로드부터 클로드 코드 등록까지 자동으로 끝납니다.

설치 후 **클로드 코드를 새로 켜야** 도구가 보입니다. 그다음엔 슬래시 명령 없이 그냥
한국어로 말하면 됩니다.

---

## 3. API — 내 메모를 코드로 다루기

MCP도 클로드 코드도 없이, **HTTP로 직접** 콩메모 데이터를 읽고 쓸 수 있습니다.
파이썬, 자바스크립트, n8n 같은 자동화 도구, `curl` 한 줄로도 됩니다.

```bash
# 저장해둔 링크 전부 뽑기
curl -s -X POST "https://iiaqvhqnafqrrxizlofl.supabase.co/rest/v1/rpc/mcp_search_items" \
  -H "apikey: sb_publishable_hh_54DP6aBLlXMVhA__Ulg_EEPrBWKu" \
  -H "Content-Type: application/json" \
  -d "{\"p_key_hash\":\"$KEY_HASH\",\"p_query\":\"http\",\"p_type\":\"link\"}"
```

앱에서 발급한 키 하나면 되고, 봇을 만들거나 서버를 띄울 필요가 없습니다.
키당 분당 60회 제한이 있습니다.

**→ [전체 API 문서 보기](API.md)**

## 안전에 대해

- 두 프로그램 모두 **앱에서 발급한 API 키**로만 동작하고, 키는 SHA-256 해시로만 서버에 저장됩니다
- 서버에서는 **키 주인의 데이터만** 조회·기록됩니다 (Postgres `SECURITY DEFINER` 함수로 강제)
- 앱에서 키를 폐기하면 **즉시 서버에서 막힙니다** — PC에 남아 있어도 소용없습니다
- 로컬 폴더 경로는 **사용자 PC에만** 저장됩니다. 서버도 앱도 그 경로를 모릅니다

## 요구사항

- Python 3.10 이상
- [Claude Code](https://claude.com/claude-code)
- 콩메모 계정 (앱에서 무료 가입)
